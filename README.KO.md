# Workout Planner

[English](README.md) · [العربية](README.AR.md) · [Čeština](README.CZ.md) · [Dansk](README.DA.md) · [Deutsch](README.DE.md) · [Español](README.ES.md) · [Français](README.FR.md) · [हिन्दी](README.HI.md) · [Bahasa Indonesia](README.ID.md) · [Italiano](README.IT.md) · [日本語](README.JA.md) · 한국어 · [Nederlands](README.NL.md) · [Norsk bokmål](README.NO.md) · [Polski](README.PL.md) · [Português (Brasil)](README.PT-BR.md) · [Português (Portugal)](README.PT.md) · [Română](README.RO.md) · [Русский](README.RU.md) · [Shqip](README.SQ.md) · [Türkçe](README.TR.md) · [Українська](README.UK.md) · [简体中文](README.ZH.md) · [繁體中文](README.ZH-TW.md)

**Obsidian을 위한 올인원 운동 기록 앱.** 웨이트 트레이닝, 달리기, 사이클링, 요가, 또는 직접 정의한 필드를 가진 운동까지 기록하세요. 휴대폰에서 세트를 기록하고, 가이드 세션을 따라 하고, 차트, 대시보드, 근육 히트맵으로 진행 상황을 확인할 수 있습니다. CSV 파일 하나, 24개 언어 지원.

휴대폰에 맞춘 앱입니다. 훈련하면서 각 세트, 달리기, 자세를 기록하고, 훈련 계획을 세우는 바로 그 노트 안에서 표, 차트, 대시보드로 진행 상황을 확인하세요. 세트는 볼트 안의 CSV 파일 하나에 저장됩니다. 계정도, 클라우드도 필요 없습니다.

차트는 추세를 보여주고, 근육 히트맵은 무엇을 훈련했는지 보여주며, 각 세트는 자신의 kg/lb 단위를 유지합니다. Dataview에서 세트를 조회할 수도 있습니다.

## 기능

- 마지막 세트 값이 자동으로 채워지는 반복 횟수와 무게 기록, +/− 버튼, 한 번의 탭으로 고르는 최근 운동
- 눈앞의 원판이 무엇을 가리키든 kg 또는 lb로 세트 기록
- 드롭 세트, 마이오 렙, 레스트 퍼즈, 슈퍼세트, 21s 또는 직접 만든 프로토콜로 세트 표시
- 날짜별로 묶이고 하루 합계가 표시되는 세트 표, 한 번의 탭으로 편집
- 오늘의 세트를 휴대폰에서 채울 수 있는 행으로 표시: 세트를 체크하면 기록되고 휴식 타이머가 시작됩니다
- 무게, 볼륨, 반복 횟수, 지속 시간, 거리, 페이스, 심박수 차트와 성장 여부를 분명하게 알려주는 추세
- 주간 연속 기록(주간 목표 포함), 훈련 달력, 개인 기록, 총 볼륨, 최근 운동, 프로토콜 통계를 보여주는 대시보드
- 앞면과 뒷면을 보여주는 근육 히트맵, 볼륨, 세트 또는 반복 횟수 기준
- 프리셋이 있는 휴식 타이머(카운트다운, 인터벌, 스톱워치). 세트를 기록하면 다시 시작되고, iOS와 Android에서 알림음이 울림
- 운동 노트를 한 번에 한 종목씩 안내하는 가이드 세션
- 계획한 운동이 얼마나 걸리는지 추정
- 근력, 맨몸, 시간 기반, 거리, 유산소 운동 또는 직접 정의한 필드
- Dataview와 Templater에서 읽을 수 있는 모든 세트가 담긴 평범한 CSV 파일 하나
- 휴대폰에 맞춘 설계: 좌우 스크롤 없음, 버튼은 늘 손이 닿는 곳에
- 24개 언어 지원

## 시작하기

플러그인을 처음 설치하면 예제 노트(샘플 운동 종목, 6주치 기록이 있는 운동 루틴 두 개, 대시보드, 기능 소개)를 추가하고, 플러그인이 그 예제를 사용하도록 설정한 뒤 **시작 가이드**를 엽니다. 기능마다 짧은 페이지 하나씩 있으며, 직접 해볼 수 있는 예제가 들어 있습니다. 설정을 열 필요는 없습니다. 자신만의 노트를 만들기 전에 마음껏 둘러보세요.

### 가이드 투어

투어는 표, 차트, 대시보드, 타이머가 있는 "가이드 투어" 노트를 열고, 각각을 차례로 가리킵니다. 짧은 단계 아홉 개로 구성됩니다.

1. **+** 버튼으로 첫 세트를 기록하세요. 저장하면 이 단계가 끝납니다.
2. 각 행의 버튼으로 세트를 편집하거나 삭제하세요.
3. 차트에서 진행 상황을 확인하세요.
4. 대시보드에서 합계와 추세를 확인하세요.
5. 근육 히트맵에서 훈련한 근육을 확인하세요.
6. 휴식 타이머를 시작하세요. 시작을 누르면 이 단계가 끝납니다.
7. 리본에 있는 덤벨 아이콘을 찾으세요. 어느 노트에서든 기록 양식을 엽니다. 휴대폰에서는 명령 팔레트를 사용하세요.
8. 명령 팔레트에서 **운동 표 삽입**, **운동 차트 삽입**, **운동 타이머 삽입**, **운동 대시보드 삽입** 중 아무 명령이나 실행하세요. 실행하면 이 단계가 끝납니다.
9. 완료.

**이전**과 **다음**으로 이동하고, **건너뛰기**로 투어를 나갈 수 있습니다. 투어가 가리키는 노트 부분이 화면 밖에 있으면 **나에게 보여주세요**가 그곳으로 스크롤합니다. 언제든 `Esc`를 누르면 투어가 끝납니다. 투어 노트를 닫거나 다른 파일로 전환해도 투어가 끝납니다. 잃는 것은 없습니다. 세트는 기록에 그대로 남습니다.

예제 데이터를 사용 중이라면 투어는 그 데이터로 진행됩니다. 그렇지 않으면 자신의 기록으로 진행되므로, 차트와 대시보드는 거의 비어 있는 상태로 시작합니다. 노트는 한 번만 만들어지며, 예제 옆이나 볼트 맨 위에 생깁니다. 기존 노트는 절대 덮어쓰지 않으며, 원하면 편집하거나 삭제할 수 있습니다. "가이드 투어"라는 이름의 노트가 이미 있고 투어가 만든 노트가 아니라면, 투어는 대신 "가이드 투어 1"(또는 다음 빈 번호)을 사용합니다.

투어를 다시 하고 싶나요? **설정 → Workout Planner → 시작하기**에서 **투어 시작**을 선택하거나, 명령 팔레트에서 **투어 시작** 명령을 실행하세요.

예제나 가이드를 다시 보고 싶나요? **설정 → Workout Planner → 시작하기**에서 **예시 만들기** 또는 **시작 가이드 열기**를 선택하거나, 명령 팔레트(`Ctrl/Cmd + P`)에서 **예제 노트 생성** 또는 **시작 가이드 열기** 명령을 실행하세요. 예제를 만든다고 해서 기존 파일이 덮어써지지는 않습니다. 다시 실행하면 없는 예제 파일만 추가되며, 수정한 파일은 그대로 유지됩니다. 가이드는 예제가 아직 없으면 예제를 만들지 물어봅니다. 비어 있는 표, 차트, 대시보드에는 **또는 예제 데이터로 살펴보기** 링크도 있습니다. 이미 운동 기록이 있다면 예제는 자체 기록 파일을 갖고, 여러분의 기록은 건드리지 않습니다.

노트에 표를 추가하려면, 예를 들어 `Push Day` 노트에서 다음과 같이 입력하세요:

````markdown
```workout-log
exercise: Bench Press
```
````

표 아래의 **+**를 탭하고 반복 횟수와 무게를 입력한 뒤 저장하세요. 표는 스스로 갱신됩니다. 블록을 직접 손으로 쓸 필요도 없습니다. **운동 차트 삽입**, **운동 표 삽입**, **운동 타이머 삽입**, **운동 대시보드 삽입**, **운동 시간 삽입** 명령을 실행하면 양식이 열리고 블록을 대신 넣어 줍니다.

## 세트 기록하기

**+** 버튼(표 아래, 운동 종목이 자동으로 채워짐), 리본의 덤벨 아이콘, 또는 **운동 기록 만들기** 명령으로 기록 양식을 여세요. 양식은 마지막 세트 값에서 시작하므로, 대부분의 경우 **+/−**를 한 번 누르고 저장하면 됩니다. 휴식이 끝나기 전에 마치세요.

양식은 운동에 맞는 필드를 묻습니다. 스쿼트라면 반복 횟수와 무게, 플랭크라면 초, 달리기라면 거리와 시간입니다([운동 유형](#운동-유형) 참고). 각 세트에는 메모와 프로토콜도 함께 기록할 수 있으며, 프로토콜은 표에 배지로 표시됩니다.

무게 필드에는 kg/lb 선택기가 있어서, 설정이 kg여도 225 lb로 기록할 수 있습니다. 표에는 그 세트가 "225 lb"로 표시되고, 차트, 통계, 볼륨은 모든 세트를 설정 단위로 환산합니다.

노트에서 세트를 기록하면 노트 이름이 그 세트의 **운동 루틴**으로 저장되므로, `workout: Push Day`가 지정된 표나 차트가 나중에 그 세트를 찾아냅니다.

## 표

`workout-log` 블록은 운동 종목이나 운동 루틴의 세트를 최신순으로 보여줍니다. 같은 날의 세트는 그날 합계가 있는 행 아래 묶이며, 각 행에는 편집 버튼이 있습니다. 세트를 삭제하려면 편집 양식을 사용하세요. 휴대폰에서는 각 세트가 좌우 스크롤 없이 간결한 행이 됩니다.

<img src="assets/tables.png" width="720" alt="휴대폰에서 본 workout-log 표: 세트가 날짜별로 묶여 시간과 드롭 세트 배지가 표시되고, + 버튼을 누르면 기록 양식이 열림">

```workout-log
exercise: Bench Press
dateRange: 14
targetWeight: 100
targetReps: 8
```

`targetWeight`와 `targetReps`를 지정하면 표 위에 점진적 과부하 목표가 나타납니다.

<details>
<summary>모든 매개변수</summary>

| 매개변수                     | 기본값  | 역할                                                 |
| ---------------------------- | ------- | ---------------------------------------------------- |
| `exercise`                   | —       | 이 운동 종목만 표시                                  |
| `workout`                    | —       | 이 운동 루틴만 표시(노트 이름)                       |
| `exactMatch`                 | `false` | 운동 종목 이름을 정확히 일치                         |
| `dateRange`                  | 전체    | 오늘과 이전 N일                                      |
| `limit`                      | `50`    | 최대 행 수. `sets`가 있으면 `sets × 2`(운동 루틴 두 개) |
| `sortBy`                     | `date`  | `date`, `exercise`, `weight`, `reps` 또는 `volume`   |
| `sortOrder`                  | `desc`  | `asc` 또는 `desc`                                    |
| `columns`                    | 전체    | 표시할 열, 예: `["date", "reps", "weight"]`          |
| `showProtocol`               | `true`  | 프로토콜 배지 열 표시                                |
| `showAddButton`              | `true`  | **+** 버튼 표시                                      |
| `targetWeight`, `targetReps` | —       | 표 위에 점진적 과부하 목표 표시                      |
| `sets`                       | —       | 계획된 세트 수, `workout-session` 블록이 집계        |

기본적으로 운동 이름은 느슨하게 일치합니다("squat"은 "Squat (high bar)"를 찾습니다). 정확히 그 이름만 원하면 `exactMatch: true`를 추가하세요.

</details>

## 휴대폰에서 세트 기록

`workout-sets` 블록은 헬스장에서 기록하도록 만들어졌습니다. 한 운동 종목의 오늘 세트를 채울 행으로 보여 줍니다. 각 행에는 같은 세트를 지난번에 했을 때의 값이 표시되므로, 바뀐 값만 입력하면 됩니다(빈 칸은 그 값으로 기록됩니다). 행을 체크하면 세트가 기록에 들어가고, 행은 기록된 세트가 되며, 맨 위의 휴식 타이머가 저절로 시작됩니다. 기록된 세트의 펼침 버튼(꺾쇠)으로 프로토콜과 메모를 바꿀 수 있고, 다시 체크하면 세트가 취소됩니다. **실행 취소**는 몇 초 동안 나타납니다.

<img src="assets/sets.png" alt="휴대폰의 workout-sets 카드: 지난번 값으로 채운 네 행, 그다음 체크된 두 세트와 돌아가는 휴식 타이머, 마지막으로 레스트 퍼즈 프로토콜을 고르고 메모를 추가하려고 연 행">

```workout-sets
exercise: Squat
sets: 4
rest: 120
```

명령 팔레트에서 **운동 세트 추가**를 실행하면 블록이 만들어지고, ⋮ 메뉴에서 블록이나 휴식 타이머를 편집할 수 있습니다.

<details>
<summary>모든 매개변수</summary>

| 매개변수                     | 기본값        | 역할                                                                                             |
| ---------------------------- | ------------- | ------------------------------------------------------------------------------------------------ |
| `exercise`                   | —             | 운동 종목(정확한 이름)                                                                           |
| `workout`                    | 노트 이름     | 세트를 기록할 운동 루틴                                                                          |
| `sets`                       | 지난번과 같음 | 채울 행 수(최소 하나). **세트 추가**로 더 늘릴 수 있음                                          |
| `targetWeight`, `targetReps` | —             | 한 번도 하지 않은 운동의 힌트, 그리고 점진적 과부하 목표                                         |
| `rest`                       | —             | 각 세트 후 휴식(초). `0`이면 타이머 없음. 비워 두면 같은 섹션의 `workout-timer`                 |
| `timer.*`                    | —             | 휴식 타이머의 나머지 옵션: `timer.type`, `timer.preset`, `timer.rest`, `timer.rounds`, `timer.showControls`, `timer.sound` |

</details>

## 차트와 추세

`workout-chart` 블록은 시간에 따른 하나의 지표를 그립니다. 무게, 볼륨, 반복 횟수, 추정 1RM, 지속 시간, 거리, 페이스, 심박수 중 하나입니다. 헤더에는 추세가 **증가**, **안정**, **감소** 중 무엇인지 표시됩니다. 안정은 전체 기간 동안 추세선이 평균의 5% 미만으로 움직인다는 뜻이므로, 느리고 꾸준한 향상도 증가로 집계됩니다. 페이스는 낮을수록 좋으므로, 선이 내려가면 개선으로 표시됩니다. 휴대폰에서는 차트가 같은 값을 담은 표로 바뀝니다.

`type: e1rm`을 쓰면 날짜별 최고 추정 1회 최대 중량(Epley: `무게 × (1 + 반복 횟수 / 30)`)을 볼 수 있습니다. 무게가 양수이고 반복 횟수가 1에서 12 사이의 정수인 세트만 포함되며, 워밍업 세트와 드롭 세트는 제외됩니다. 해당 세트가 없는 날은 생략됩니다. 추정치는 kg/lb 설정을 따릅니다. 기본 근력 차트는 여전히 볼륨입니다.

```workout-chart
exercise: Bench Press
type: e1rm
dateRange: 180
```

API의 `getExerciseStats`에는 `estimatedOneRepMax`가 추가됩니다. 설정된 무게 단위의 최고 추정치이며, 해당 세트가 없으면 `null`입니다. 기존 PR 필드와 CSV 열은 그대로입니다.

## 대시보드와 근육 히트맵

`workout-dashboard` 블록은 네 가지 숫자로 시작합니다. 총 운동 횟수, 주간 연속 기록, 총 볼륨, 개인 기록입니다. 그 아래에는 주, 월, 연 단위 빠른 통계, 볼륨 추세, 최근 운동, 프로토콜 통계, 계획된 운동 시간과 실제 운동 시간 비교, 그리고 훈련 달력이 있습니다. 훈련 달력은 1년 동안의 훈련일을 볼륨에 따라 음영으로 보여주며, 현재 연속 기록과 최고 연속 기록도 함께 표시합니다. 한 주는 주간 목표(설정 → 주간 목표, 기본값 1)만큼의 훈련일을 채우면 연속 기록에 포함됩니다. 휴대폰에서는 빠른 작업이 먼저 나오고, 요약은 2 × 2 격자로 표시됩니다.

<img src="assets/dashboard.png" width="720" alt="휴대폰의 대시보드: 요약, 이번 주 목표를 달성한 훈련 달력, 최근 운동, 빠른 통계">

```workout-dashboard
title: Last three months
dateRange: 90
widgets: [summary, heatMap, volume, recentWorkouts]
```

YAML을 직접 쓰지 않고 위젯과 순서를 고르려면 **운동 대시보드 삽입** 명령으로 대시보드를 넣거나, 삽입된 대시보드 오른쪽 위의 ⋮ 메뉴를 열어 **대시보드 편집**을 선택하세요.

그 창에서 **레이아웃**을 **그리드**로 설정하면, 인벤토리 아이템처럼 위젯을 직접 배치할 수 있습니다. 위젯을 드래그해 옮기고, 모서리를 드래그해 넓이나 높이를 바꾸며, 격자 아래에 놓으면 위젯이 빠집니다. 키보드도 됩니다. 화살표는 이동, Shift와 화살표는 크기 조정, Delete는 위젯 제거입니다. 격자의 열 수는 노트 너비에 맞게 정해집니다. 더 좁은 창에서는 위젯이 읽는 순서대로 다시 배치되고, 휴대폰에서는 쌓입니다. 레이아웃은 그대로 저장됩니다. 노트가 한 열(휴대폰)만 보여줄 때는, 편집 창이 저장된 열 수를 기준으로 몇 열로 편집할지 물어봅니다. 블록은 위젯마다 한 줄(열, 행, 너비, 높이)을 유지합니다:

```workout-dashboard
layout: grid
columns: 3
grid.summary: 1 1 3 1
grid.heatMap: 1 2 2 2
grid.recentWorkouts: 3 2 1 1
```

히트맵은 지난 1주, 1개월, 1년 동안 어떤 근육을 훈련했는지 앞면과 뒷면으로, **볼륨**, **세트**, **반복** 기준으로 보여줍니다. 3주 동안 하체를 건너뛰었다는 사실을 알아채는 가장 빠른 방법입니다. 그 아래의 짧은 훈련 분석은 앞쪽이 뒤쪽보다 훨씬 많이 움직이는 것 같은 불균형을 경고합니다. 분석은 [운동 유형](#운동-유형)의 운동 페이지에 있는 근육 태그를 읽어서 수행합니다. 맨몸 운동과 시간 기반 운동에는 무게가 없으므로, **세트**와 **반복**에서만 표시됩니다.

## 타이머

`workout-timer` 블록은 카운트다운, 인터벌, 또는 스톱워치 타이머입니다. 자주 쓰는 휴식 시간은 프리셋으로 저장해 두세요. 타이머를 운동 종목이나 운동 루틴에 연결하면, 세트를 기록할 때마다 다시 시작되므로 세트 사이에 손댈 필요가 없습니다. `autoStart: true`를 설정하면 노트를 열자마자 시작됩니다.

<img src="assets/timers.png" width="320" alt="휴대폰의 타이머 두 개: 휴식 단계의 인터벌 타이머와 2라운드 운동 단계의 Tabata 프리셋">

타이머는 iOS와 Android에서도 알림음을 냅니다. 휴대폰은 페이지를 한 번 터치한 뒤에만 소리를 허용하므로, `autoStart`로 시작한 타이머는 **시작**을 한 번 누르기 전까지 조용합니다.

설정 → Workout Planner → **타이머 장치 관련 알림**에서 **타이머가 실행되는 동안 화면 켜두기**가 기본으로 켜져 있습니다. 기기가 허용하는 경우, 포그라운드에서 실행 중인 타이머가 하나라도 있으면 화면 꺼짐 방지를 요청합니다. **타이머가 완료될 때 진동**은 기본으로 꺼져 있으며, 소리와 별개로 0이 되는 순간 짧게 진동합니다(안드로이드 같은 지원 기기에서). iOS는 기존 오디오 알림을 유지하며, iOS에서는 웹 진동을 쓸 수 없습니다. 이 기능들은 최선을 다해 브라우저 API를 사용하며, 아직 실제 Android/iOS 기기에서 검증되지 않았습니다. 백그라운드 알람은 제공하지 않습니다. `id`가 있는 타이머는 노트를 바꿔도 계속 실행되며, 일시정지하거나 끝나게 두면 화면 꺼짐 방지가 해제됩니다.

```workout-timer
type: countdown
duration: 90
exercise: Bench Press
```

인터벌 타이머는 운동과 휴식을 번갈아 할 수 있습니다. 화면에는 **운동** 또는 **휴식**이 표시되고, 각 단계는 자체 알림음으로 시작합니다. 각 라운드는 운동 뒤에 휴식이 오며, 마지막 라운드도 예외가 아닙니다. 따라서 이 Tabata는 4분 동안 진행됩니다:

```workout-timer
type: interval
work: 20
rest: 10
rounds: 8
```

`preset: Tabata`(운동 20초, 휴식 10초, 8라운드)와 `preset: EMOM`(10분 동안 매분 한 라운드)은 기본으로 내장되어 있습니다. 같은 이름의 저장된 프리셋이 있으면 그것이 내장 프리셋을 대체합니다.

<summary>모든 매개변수</summary>

| 매개변수              | 기본값      | 역할                                                                 |
| --------------------- | ----------- | -------------------------------------------------------------------- |
| `type`                | `countdown` | `countdown`, `interval` 또는 `stopwatch`                             |
| `duration`            | `30`        | 초 단위(카운트다운; 인터벌에서는 라운드당 운동 시간)                 |

## 가이드 세션

운동 노트 맨 위에 있는 `workout-session` 블록(명령 **가이드 세션 삽입**)은 한 번에 한 종목씩 안내합니다. 현재 몇 번째 세트인지, 목표, 지난번에 한 기록, **세트 기록** 버튼, 그리고 세트를 기록하면 시작되는 휴식 타이머를 보여줍니다.

![휴대폰의 가이드 세션: 스쿼트 4세트 중 3세트에서 세션과 세트 카드 모두 휴식이 돌아가는 모습, 세트 기록으로 연 기록 양식, 그다음 다음 운동 종목의 휴식 타이머가 돌아가는 모습](assets/session.png)

````markdown
```workout-session
```

## Squat

```workout-sets
exercise: Squat
sets: 4
targetReps: 8
targetWeight: 100
rest: 180
```
````

노트 자체가 계획입니다. `exercise`가 있는 각 `workout-log` 또는 `workout-sets` 블록이 한 단계이며, 나타나는 순서대로 `sets`, `targetReps`, `targetWeight`를 가집니다. 휴식 시간은 `workout-sets` 블록의 `rest`에서 가져오고, 없으면 같은 `##` 섹션의 `workout-timer`에서 가져옵니다(없으면 기본 프리셋을 씁니다). 세션과 세트 카드는 하나의 카운트다운을 공유합니다. 세션은 이 운동 루틴에서 오늘 기록한 세트를 셉니다. 그래서 노트를 다시 열어도 하던 곳에서 이어집니다. `sets`가 없는 운동 종목은 이후 종목의 세트를 기록할 때까지 현재 단계로 남으며, **이전**과 **다음**으로 자유롭게 이동할 수 있습니다.

## 운동 시간

`workout-duration` 블록은 운동 노트가 얼마나 걸리는지 추정합니다. 타이머의 휴식 시간과 각 세트에 드는 시간을 더하고, 지난번 실제 세션이 얼마나 걸렸는지도 옆에 보여 줍니다.

<img src="assets/duration.png" width="420" alt="예상 운동 시간 카드: 휴식 시간, 세트 시간, 지난 세션">

```workout-duration
workout: Workouts/Push Day.md
```

`workout`에는 볼트 안의 경로, 이 노트 기준의 상대 경로, 또는 노트 이름만 넣을 수 있습니다. 생략하면 현재 노트를 추정합니다. 반복당 및 세트당 초는 [설정](#설정)에서 가져옵니다.

## 운동 유형

운동 페이지는 운동 폴더에 있는 노트입니다. 그 frontmatter는 기록 양식이 무엇을 물어야 하는지, 그리고 어떤 근육을 훈련하는지를 정합니다. **운동 페이지 만들기**를 실행하면 하나를 만들어 줍니다.

```yaml
---
exercise_type: strength
tags:
  - chest
  - triceps
---
```

| `exercise_type`      | 기록 양식이 묻는 항목                         | 함께 인식되는 값                                             |
| -------------------- | -------------------------------------------- | ------------------------------------------------------------ |
| `strength` (기본값)  | 반복 횟수, 무게                              | `bodyweight`, `weights`                                      |
| `timed`              | 지속 시간                                    | `duration`, `time`, `timer`, `interval`, `hold`, `isometric` |
| `distance`           | 거리, 지속 시간(선택)                        | `running`, `run`                                             |
| `cardio`             | 지속 시간, 거리, 심박수(선택)                | —                                                            |
| `custom`             | `parameters`에 나열한 필드만                 | —                                                            |

요가도 같은 방식입니다. 각 자세가 `timed` 운동이므로, 양식은 자세를 얼마나 오래 유지했는지만 묻습니다. 예제 노트에는 가이드 세션이 포함된 아침 요가 흐름이 들어 있습니다.

![휴대폰의 요가 흐름: Downward Dog에 대한 가이드 세션, 유지 시간만 묻는 기록 양식, 그리고 첫 유지 기록이 있는 세트 카드](assets/yoga.png)

`type:`은 `exercise_type:`과 똑같이 작동합니다. `parameters` 아래에 직접 필드를 추가할 수 있습니다. 예를 들어 줄넘기의 라운드 수는 다음과 같습니다:

```yaml
---
exercise_type: timed
parameters:
  - key: rounds
    label: Rounds
    type: number
    required: false
---
```

운동을 기록한 뒤 운동 유형을 바꾸면 **운동 변환**이 기존 세트를 옮기고, 이전 필드가 어디로 가야 하는지 고를 수 있게 합니다.

## 내 데이터

모든 세트는 `workout_logs.csv`의 한 행입니다. 스프레드시트로 열거나, 백업하거나, 다른 파일과 똑같이 동기화할 수 있습니다.

```csv
date,exercise,reps,weight,volume,origine,workout,timestamp,notes,protocol
2025-01-17T10:30:00.000Z,Bench Press,8,100,800,[[Push Day]],Push Day,1737138600000,,standard
```

<details>
<summary>열 설명과 직접 편집</summary>

| 열                         | 의미                                |
| -------------------------- | ----------------------------------- |
| `date`                     | 세트를 기록한 시각(ISO 8601)        |
| `exercise`, `workout`      | 운동 종목과 운동 루틴 이름          |
| `reps`, `weight`, `volume` | 볼륨은 반복 횟수 × 무게             |
| `origine`                  | 기록한 노트로 가는 링크             |
| `timestamp`                | 행의 고유 ID(밀리초)                |
| `notes`, `protocol`        | 자유 메모와 훈련 기법               |

고유한 필드를 가진 운동 유형(`duration`, `distance`, `heartRate`, 또는 `parameters`)은 끝에 열을 추가합니다. 마지막 열인 `weightUnit`은 `kg` 또는 `lb`이며, 해당 행의 `weight`와 `volume` 단위입니다. 값이 비어 있으면 설정의 단위를 뜻합니다.

파일을 직접 편집한다면 헤더 행을 유지하고, 쉼표, 따옴표, 줄바꿈이 들어 있는 값은 큰따옴표로 감싸세요. `=`, `+`, `-`, `@`로 시작하는 메모는 스프레드시트가 수식으로 실행하지 않도록 앞에 `'`를 붙여 저장되며, 플러그인은 이 `'`를 다시 숨깁니다.

</details>

모든 데이터는 볼트 안에 남습니다. 플러그인은 복사 배지(대시보드의 근육 태그)를 클릭할 때만 클립보드에 쓰며, 클립보드를 읽지는 않습니다.

### Dataview와 Templater

플러그인은 로드된 뒤 `WorkoutPlannerAPI`(또는 `window.WorkoutPlannerAPI`)를 제공합니다.

```dataviewjs
const s = await WorkoutPlannerAPI.getExerciseStats("Bench Press");
dv.paragraph(`Best: ${s.prWeight} × ${s.prReps} on ${s.prDate}`);
```

<details>
<summary>API 참조와 추가 예제</summary>

| 메서드                       | 반환값                                                                                                                                                                                                                                                  |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `getWorkoutLogs(filter?)`    | 세트 목록. 각 세트는 `date`, `exercise`, `reps`, `weight`, `volume`, `workout`, `notes`, `timestamp`, `protocol`을 가집니다. `weight`와 `volume`은 설정 단위이고, `enteredWeight`와 `enteredUnit`은 기록할 때 입력한 값입니다                                     |
| `getExerciseStats(exercise)` | `estimatedOneRepMax`, `totalVolume`, `maxWeight`, `prWeight`, `prReps`, `prDate`, `totalSets`, `averageWeight`, `averageReps`, `lastWorkoutDate`, `trend`                                                                                               |
| `getExercises(filter?)`      | 정렬된 운동 종목 이름: 운동 페이지의 파일 이름(하위 폴더 포함), 또는 운동 페이지가 없을 때는 기록에 있는 이름. `{ tag: "chest" }`는 해당 태그가 있는 페이지의 운동만 남기므로, 운동 페이지가 없으면 결과가 비어 있습니다.                                       |

`getWorkoutLogs`는 `exercise`(부분 일치, 대소문자 무시), `workout`, `dateRange: { start, end }`, `protocol`, `exactMatch`를 받습니다.

Dataview에서 최근 스쿼트 기록 보기:

```dataviewjs
const logs = await WorkoutPlannerAPI.getWorkoutLogs({
  exercise: "Squat",
  dateRange: { start: moment().subtract(30, "days").format("YYYY-MM-DD") },
});
dv.table(
  ["Date", "Reps", "Weight"],
  logs.map((l) => [l.date.slice(0, 10), l.reps, l.weight]),
);
```

[Templater](https://github.com/SilentVoid13/Templater) 템플릿에서 최신 수치로 노트를 시작하려면:

```markdown
## Squat

<%\*
const s = await WorkoutPlannerAPI.getExerciseStats("Squat");
tR += s.totalSets
? `Best ${s.prWeight} × ${s.prReps} (${s.prDate}), last session ${s.lastWorkoutDate}`
: "No squats logged yet";
%>
```

</details>

## 설정

CSV 및 운동 폴더, 기본 무게 단위, **+/−** 버튼의 무게 증가 단위, 타이머 프리셋, 나만의 프로토콜(이름, 짧은 라벨, 색상), 그리고 지속 시간 추정에 쓰는 반복당 및 세트당 초를 설정하세요. **고급** 아래의 **모두 실행**은 업그레이드 후 모든 유지보수 작업을 실행합니다.

무게 단위를 바꿔도 기존 세트의 라벨은 바뀌지 않습니다. 각 세트는 기록된 단위를 그대로 유지합니다.

## 문제 해결

- **충돌: Workout Block (`workout-block`).** 두 플러그인 모두 `workout-log` 코드 블록을 등록하고, 기본 기록 파일 이름으로 `workout_logs.csv`를 사용합니다. 둘 중 하나를 쓰기 전에 한쪽 플러그인을 비활성화하세요.

- **표나 차트가 비어 있습니다.** 운동 이름과 `dateRange`를 확인하세요(차트의 기본값은 최근 30일). `exactMatch: true`이면 이름이 정확히 일치해야 합니다.
- **히트맵에 운동이 빠져 있습니다.** 해당 페이지에 근육 `tags`가 있어야 하고, 운동 폴더 안에 있어야 합니다. 맨몸 운동과 시간 기반 운동은 **세트** 또는 **반복**에서만 보입니다.
- **플랭크인데 기록 양식이 반복 횟수와 무게를 묻습니다.** 운동 페이지에 `exercise_type: timed`를 설정하세요.
- **휴대폰에서 타이머 소리가 나지 않습니다.** **시작**을 한 번 누르세요. 휴대폰은 페이지를 터치하기 전까지 소리를 막습니다.

## 설치

### 커뮤니티 플러그인에서 설치

1. **설정 → 커뮤니티 플러그인**을 여세요
2. **Workout Planner**를 검색하세요
3. **설치**를 선택한 다음 **활성화**를 선택하세요

### 수동 설치

1. [최신 릴리스](https://github.com/SpatariuRares/obsidian-workout-plugin/releases/latest)에서 `main.js`, `manifest.json`, `styles.css`를 내려받으세요
2. `your-vault/.obsidian/plugins/workout-planner/` 폴더를 만드세요
3. 내려받은 파일을 그 폴더에 복사하세요
4. **설정 → 커뮤니티 플러그인**에서 플러그인을 활성화하세요
