# Review repo: piano di lavoro (2026-10-09)

Questa review copre tutta la repo allo stato del commit `1ff0df0`, ed è stata fatta su due assi:

- **Standards**: il codice viene confrontato con CLAUDE.md, GUIDE_LINES.MD e la smell baseline di Fowler.
- **Spec**: il codice viene confrontato con quello che promettono README.md, CONTEXT.md e CLAUDE.md.

L'hanno svolta 6 agenti in sola lettura. Sei dei punti più gravi sono stati ricontrollati a mano e sono contrassegnati da ✅. I numeri di riga si riferiscono al commit `1ff0df0` e possono essersi spostati.

Ogni voce porta un'etichetta:

- `[Spec]`: il codice non fa quello che la documentazione promette.
- `[Std]`: violazione di uno standard documentato.
- `[Smell]`: un giudizio, non un obbligo.
- `[Doc]`: va corretta solo la documentazione.

Dove compare **Decisione**, bisogna scegliere tra implementare la funzione e togliere la promessa dalla documentazione.

Dopo ogni blocco, per verificare: `npm run typecheck && npm run lint && npm test && npm run doe:validate`.
